# Study Planner

A C# desktop application developed as a university coursework project for comparing Events and Delegates in .NET.

## Features
- Task management system
- Event vs Delegate implementation
- MVVM architecture
- JSON persistence
- Input validation
- ObservableCollection synchronization
- Linux/Windows compatible logic

## Purpose
The project demonstrates:
- encapsulation using events
- delegate flexibility through callbacks
- differences in software stability and architecture

## Technologies
- C#
- .NET
- MVVM
- JSON Serialization
- WPF
